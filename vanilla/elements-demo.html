✨ Features

Ygdrassil Web Components provide:

  • Declarative Syntax: Define states in HTML
  • URL Synchronization: States persist in the URL hash
  • Transition Control: Define allowed state transitions
  • Event System: Listen to state changes
  • No Build Required: Works directly in browsers
  • Progressive Enhancement: Degrades gracefully

All the power of Ygdrassil state machines, now accessible through simple HTML tags!

📝 Example Code

Here's how simple it is to create a state machine:

<state-machine name="app" initial="home"> <state-nav to="home">Home</state-nav> <state-nav to="about">About</state-nav> <state-def name="home"> <h1>Home Page</h1> <p>Welcome to my app!</p> </state-def> <state-def name="about"> <h1>About Page</h1> <p>Built with Ygdrassil</p> </state-def> </state-machine>

Note: This state has restricted transitions - you can only navigate to Welcome, Features, or API from here!

🔧 API Reference

<state-machine>

  • name - Machine identifier (default: "default")
  • initial - Initial state to activate

<state-def>

  • name - State name (required)
  • transition - Comma-separated allowed next states
  • onenter - Global function name to call on enter
  • onexit - Global function name to call on exit

<state-nav>

  • to - Target state (required)
  • type - "button" or "link" (default: "button")
  • machine - Target machine name (default: parent)
  • data-* - Query parameters to pass

<state-query>

  • format - "json" or "list" (default: "json")
  • machine - Target machine name (default: parent)
