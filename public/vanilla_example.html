📖 About Ygdrassil

Ygdrassil is a lightweight state machine library that synchronizes your application state with the URL hash and query parameters.

Key benefits:

  • Bookmarkable States: Every state has a unique URL
  • Zero Dependencies: Pure vanilla JavaScript
  • Web Components: Use custom HTML elements
  • Type Safe: Works great with TypeScript
  • Small Bundle: Minimal footprint

✨ Features

Ygdrassil Vanilla provides:

  • Declarative HTML: Define states using custom elements
  • State Transitions: Control which states can navigate to others
  • Lifecycle Hooks: onEnter and onExit callbacks
  • Query Parameters: Pass data between states
  • Multiple Machines: Run several state machines simultaneously
  • Event System: Listen to state changes with custom events
  • Progressive Enhancement: Works without JavaScript enabled

Browser Support:

Works in all modern browsers that support ES6 modules and Custom Elements.

💻 Example Code

Here's the HTML used to create this very demo:

<state-machine name="demo" initial="home"> <!-- Navigation --> <state-nav to="home">Home</state-nav> <state-nav to="about">About</state-nav> <state-nav to="features">Features</state-nav> <!-- States --> <state-def name="home"> <h2>Home</h2> <p>Welcome to Ygdrassil!</p> </state-def> <state-def name="about"> <h2>About</h2> <p>A state machine library...</p> </state-def> </state-machine> <script type="module" src="./StateMachine.elements.js"></script>

That's it! Just include the script and use the custom elements.

🚀 Getting Started

Installation

npm install ygdrassil

Usage

<!-- Include the Web Components library --> <script type="module"> import 'ygdrassil/vanilla/elements' </script> <!-- Or use in browser --> <script type="module" src="./node_modules/ygdrassil/vanilla/StateMachine.elements.js"></script>
